# Archive

Point-in-time review outputs, kept for their evidence trail (findings, file/line citations,
fix rationale) rather than as living documents. None of these are updated as the codebase
changes — treat every status/finding inside them as accurate only as of the date in the
filename or the file's own header.

Superseded by [HARDENING_PLAN.md](../HARDENING_PLAN.md) and
[HARDENING_BACKLOG.md](../HARDENING_BACKLOG.md) for anything still open; open items originally
tracked here have been carried forward into [BACKLOG.md](../BACKLOG.md) (G-numbered items) or
into the hardening docs (HP-numbered items).
