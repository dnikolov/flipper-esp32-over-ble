# Standalone FAP baseline

This is the phase 1 external FAP baseline. It targets the pinned Unleashed `unlshd-092` API 88.4 revision recorded in [docs/BASELINES.md](../docs/BASELINES.md).

The app is intentionally inert. BLE profile ownership, pairing, and protocol code belong to later roadmap phases.

Build from the pinned Unleashed firmware checkout with its external-app build tooling, using this directory as the application source directory.
